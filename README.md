# ACG World Music — Lata Mangeshkar Edition (YouTube)

This version uses the user-supplied 261-entry Lata Mangeshkar list as its catalogue source. Exact duplicates are collapsed to 211 unique song titles.

Because the project does not store copyrighted recordings, each song has a pre-filled YouTube search link designed to find the original movie recording. Where possible, choose the official/authorized upload (for example, Saregama Music).

The website does not download or redistribute audio.

## Deploy
- Build: `npm run build`
- Publish directory: `dist`

## Important
The supplied catalogue does not identify language/movie/year for every entry, so the app does not invent those fields. Marathi Classics is intentionally not populated by guessing language.
